# Sistema-de-Gestao-para-Mercearias
Sistema de gerenciamento de mercearia em Python com controle de estoque, vendas, caixa e persistência de dados em JSON.

Sistema de gerenciamento de mercearia desenvolvido em Python.

## Funcionalidades

- Cadastro de produtos
- Controle de estoque
- Registro de vendas
- Controle de caixa
- Registro de saídas de caixa
- Histórico de transações
- Persistência de dados em JSON

## Tecnologias

- Python 3
- JSON
- Programação Orientada a Objetos (POO)

## Estrutura

- Cadastro de produtos
- Atualização de estoque
- Vendas com cálculo de troco
- Controle financeiro
- Histórico completo de operações

## Como executar

Clone o repositório:

```bash
git clone https://github.com/julian-soares/mercasys.git
```

Entre na pasta:

```bash
cd mercasys
```

Execute:

```bash
python main.py
```
